# AX 해커톤 예선 · 과제 규칙 정리

출처: https://hack.primer.kr/rounds/10 (2026-07-10 확인)

## 과제

참여 기업의 공개·검증 가능한 문제를 해결하는 **Codex 플러그인**.

- 선택한 기업, 그 기업의 산업, 또는 그 기업의 고객이 겪는 **실제 문제를 공개 자료로 입증**하고, 이를 해결하는 Codex 플러그인을 제출
- 기업을 여러 개 선택했다면 **각 기업마다 별도의 플러그인**을 만들어 기업별로 따로 제출 (하나의 제출물로 여러 기업 불가)

참고 문서 (OpenAI 공식):

- 플러그인 개요: https://developers.openai.com/codex/plugins
- 플러그인 만들기: https://developers.openai.com/codex/plugins/build
- 스킬 작성법: https://developers.openai.com/codex/skills

## 제출물

### 1. submission.zip

```
submission.zip
├── src/
│   ├── .codex-plugin/plugin.json   # 필수
│   ├── skills/<이름>/SKILL.md
│   ├── .mcp.json
│   └── 그 밖의 실행 코드와 설정 파일
├── README.md
└── logs/
```

- 전체 플러그인 루트가 `src` 안에 있어야 함
- `src/.codex-plugin/plugin.json` **필수**
- plugin.json 외에 플러그인이 실제로 동작하도록 만드는 구성 요소 **1개 이상** 필요
  (스킬 `SKILL.md`가 가장 일반적, 필요시 MCP 서버 `.mcp.json`이나 실행 코드 추가)
- `src` 내부 구조는 자유이되 **Codex 플러그인으로 실행되어야 함**

### logs 폴더

- 플러그인을 만들며 AI와 주고받은 대화 로그를 `logs`에 포함
- **편집·발췌 없이 전체를 그대로** 제출 (사후 가공 시 **실격**)
- 허용 형식: `md`, `txt`, `json`, `jsonl`
- 로그·플러그인·질문지 사이 **정합성**을 평가 (어긋나면 불리)
- 로그 수집 도구: log-hooks.zip
  (https://github.com/jocoding-ax-partners/axwar/releases/download/v1.0/log-hooks.zip)
- 주의: AI 채팅에 API 키·비밀번호·토큰 등 비밀정보 입력 금지 (로그에 남음)

### 2. 질문 5문항 (기업별 사이트 입력, 문항당 800자)

1. 무엇을, 누가, 어떤 상황에서 쓰나요?
2. 왜 이 문제를 선택했나요?
3. 플러그인은 어떻게 작동하나요?
4. AI를 어떻게 활용했나요?
5. 어떻게 검증했나요?

## 채점·주의사항

- 예선 과제는 **AI와 심사자가 함께 평가**
- ⚠️ 로그 파일을 사후 가공(편집·발췌·삭제)하여 제출하면 **실격**
- 출처는 **공개 자료로 AI가 확인할 수 있어야** 함
- 기업 내부 비공개 정보, 확인 불가한 사적 경험, 출처 없는 숫자는 근거 불인정
- 예선 제출물은 본선 심사에도 활용될 수 있음
