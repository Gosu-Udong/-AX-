# 예선 5문항 답변 (사이트 입력용 · 문항당 공백 포함 800자 이내)

## 1. 무엇을, 누가, 어떤 상황에서 쓰나요?

kakaopaysec-compliance-guard는 카카오페이증권의 릴리스 전 컴플라이언스 게이트 역할을 하는 Codex 플러그인이며 세 개 스킬로 구성됩니다. (1) ad-compliance-lint는 마케팅·UI 문구(이벤트 배너·푸시·랜딩)에서 원금 보장·확정 수익·무조건 등 금소법 제22조 오인 표현, 투자위험 고지 누락, 협회 광고 표시요건을 검사합니다. (2) assertive-claims-check는 AI 챗봇 응답의 자본시장법 제49조 단정적 표현을 잡고, 응답 문장이 사내 약관·FAQ에 근거하는지(grounding)를 검증합니다. (3) pii-guard는 코드·로그의 주민번호·카드·계좌·전화·이메일 평문 노출과 국외·제3자 전송을 검출합니다. 사용자는 마케팅·개발·컴플라이언스·보안 담당자로, 배너 배포 전, AI 답변 노출 전, 커밋·릴리스 전에 CI 게이트나 로컬 CLI로 위반을 자동 1차 필터링합니다. 모든 판정에 근거 조문과 공개 출처 URL이 붙어, 사람 심의로 넘기기 전에 근거를 역추적할 수 있습니다.

## 2. 왜 이 문제를 선택했나요?

카카오페이증권은 '규제 준수까지 정확성과 근거가 검증되는 AI'를 공개적으로 지향합니다(https://www.kmjournal.net/news/articleView.html?idxno=12670). 이 지향은 세 규제 리스크로 구체화됩니다. 첫째, 투자성 광고는 금융소비자보호법 제22조가 손실보전·이익보장 오인 표현을 금지하고 투자위험 고지를 의무화하며, 위반 시 과태료 최대 1억원, 광고는 준법감시인 승인과 협회 심사필이 법적 의무입니다(https://www.law.go.kr/LSW/lsInfoP.do?lsId=013704&ancYnChk=0). 실제 '무료 주식·최대 1,000만원' 이벤트를 운영합니다(https://www.etnews.com/20260513000111). 둘째, AI 답변의 단정·환각은 자본시장법 제49조 부당권유 리스크입니다(https://www.law.go.kr/lsInfoP.do?lsiSeq=105908). 셋째, 카카오페이(그룹)는 4,045만명 개인정보 국외이전으로 과징금 129.76억 등 제재를 받아 PII 노출·전송이 실증된 초대형 리스크임이 확인됐습니다(https://www.newswhoplus.com/news/articleView.html?idxno=53738). 손실보전 형사처벌은 자본시장법 제55·445조 소관으로 광고 과태료와 조문을 분리했습니다.

## 3. 플러그인은 어떻게 작동하나요?

세 스킬 모두 python3 표준 라이브러리만 쓰는 결정론적 정적 분석기이며, 규칙·조문·출처는 references/*.json으로 분리해 데이터로 관리합니다. ad-compliance-lint는 파일을 라인 단위로 스캔해 금지 표현 정규식을 매칭하고, 배너 JSON은 항목별로 투자성 광고 여부를 판정해 위험고지 누락과 표시요건(운용실적 면책·심사필·비용 안내)을 검사합니다. assertive-claims-check는 응답을 문장으로 분해해 제49조 단정 표현을 찾고, 각 문장 토큰을 로컬 지식베이스 라인과 겹침 매칭(조사·어미 차이를 흡수하는 접두 매칭)해 근거 점수가 임계값(기본 0.5) 미만이면 미근거로 플래그하고 근거 파일:라인을 인용합니다. 임베딩·외부 API를 쓰지 않아 100% 재현됩니다. pii-guard는 카드 Luhn 검증과 계좌 자릿수 하한으로 오탐을 줄이고, 같은 라인의 로그·네트워크 sink와 국외 호스트 결합 시 심각도를 high·critical로 승급하며 출력은 PII를 마스킹합니다. 공통 계약은 argparse, 리포트와 --json, exit 0/1/2입니다.

## 4. AI를 어떻게 활용했나요?

메인 오케스트레이터(Claude)가 설계·품질관리를 맡고, 기업별 리서치·구현 서브에이전트(Opus)가 병렬로 담당 기업만 처리하도록 분업했습니다. 리서치 단계에서 서브에이전트가 WebSearch로 금소법 제22조, 자본시장법 제49조·제55조, 카카오페이 국외이전 제재 등 공개 자료를 교차검증하고, 반증 탐색을 통해 '손실보전 형사처벌=자본시장법 제55·445조 vs 광고 과태료=금소법 제22조'처럼 조문 귀속 오류를 사전에 분리·수정했습니다. 구현 단계에서는 스킬 아키텍처, 규칙 JSON, 스크립트, 가상 샘플을 생성하고, 실제로 스크립트를 실행해 위반·정상·오탐(ISO 날짜를 계좌로 오검출)을 관찰하며 규칙을 교정했습니다. 접근이 막힌 URL은 403으로 정직하게 표기하고 WebSearch로 사실을 확인했습니다. 모든 대화 원본 로그는 편집 없이 logs/에 제출합니다.

## 5. 어떻게 검증했나요?

세 스크립트를 샘플로 실제 실행해 exit code를 확인했습니다. ad-compliance-lint는 samples/marketing에서 위반 15·경고 12로 exit 1, samples/marketing_clean에서 exit 0이었습니다. assertive-claims-check는 samples/ai_responses에서 단정표현 3·미근거 3으로 exit 1(예: '100% 예금자보호'는 단정표현이자 지식베이스 근거 없음), samples/ai_responses_clean에서 exit 0이었습니다. pii-guard는 samples/pii에서 노출 8건(critical 1·high 2)으로 exit 1, samples/pii_clean에서 exit 0이었습니다. 사용오류는 exit 2를 반환했습니다. plugin.json과 references/*.json, 세 스크립트의 --json 출력을 python3 -m json.tool로 모두 검증했고, --json을 두 번 실행해 diff가 없어 결정론을 확인했습니다. 계좌 자릿수 하한으로 날짜 오탐을 제거하고, 기존 smoke 테스트가 잡던 위반을 상위호환으로 모두 검출함을 확인했습니다. 명령과 출력은 README '검증' 섹션에 기록했습니다.
