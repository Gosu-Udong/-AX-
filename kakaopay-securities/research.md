## 접근성 표기 규칙
- `WebFetch: 403` = 이 리서치 샌드박스에서 직접 fetch 시 HTTP 403 (봇 차단/프록시). 일반 브라우저·심사자 환경에서는 접근 가능한 공개 URL.
- `WebSearch: 확인` = WebSearch가 해당 URL의 본문/요지를 실제로 반환하여 사실을 확인함.
- 샌드박스 WebFetch가 성공하는 곳은 raw.githubusercontent.com류뿐이라, 한국 법령/정부/언론은 전부 403이었음. 이는 예선 규칙이 예고한 "일부 사이트 403" 상황.
