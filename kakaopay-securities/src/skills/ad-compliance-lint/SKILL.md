# ad-compliance-lint — 금융광고 문구 컴플라이언스 린터

## 언제 쓰나 (사용 시나리오)
- 마케팅팀/개발자가 이벤트 배너·푸시 문구·프로모션 랜딩 페이지를 **릴리스(배포)하기 전** 규제 위반 소지를 자동 점검하고 싶을 때.
- 컴플라이언스팀이 대량의 화면 문구를 사람 눈으로 심의하기 전에 **1차 자동 필터**로 걸러내고 싶을 때.
- 금융투자업 광고는 집행 전 **준법감시인 사전승인 + 금융투자협회 사전심의('심사필')가 법적 의무**이므로, 이 린터를 CI 게이트로 붙여 위반 문구가 심의 단계로 넘어가기 전에 차단한다.

## 무엇을 검사하나
1. **금지·오인 표현 검출**(금소법 §22②): 원금 보장, 확정 수익, 손실 없음, 무조건, 절대/100% 안전, 객관적 근거 없는 최상급·배타적 표현(수익률 1위 등).
2. **투자위험 필수 고지 누락**(금소법 §22·금투협 광고규정): 투자성 광고인데 원금손실 가능성 등 위험고지가 없으면 위반.
3. **협회 광고규정 표시요건 체크리스트**(경고): 과거 운용실적 면책 문구, 준법감시인·심사필 표기, 수수료 등 비용 안내 존재 여부.

## 실행 명령
플러그인 루트(설치 시 `src/`) 기준:
```bash
# 디렉토리 전체 검사 (사람이 읽는 리포트)
python3 scripts/ad_compliance_lint.py samples/marketing

# 위반뿐 아니라 표시요건 경고도 실패로 처리 (엄격 모드)
python3 scripts/ad_compliance_lint.py samples/marketing --strict

# CI/후속 처리용 JSON 출력
python3 scripts/ad_compliance_lint.py samples/marketing --json
```

## 입력 형식
- 대상 확장자: `.json .strings .md .txt .properties .html .xml .yaml .yml` (`--ext`로 추가 가능).
- **구조화 배너 JSON**: `{"banners":[{"id","text","is_investment_ad"}...]}` 또는 dict 값 중 객체 리스트를 자동 인식해 항목별로 평가(파일:라인 추적).
- 그 외 파일: 파일 전체를 한 광고 단위로 보고, 투자 트리거 키워드(수익률·투자·펀드·주식 등) 유무로 투자성 광고 여부를 추론.

## 출력 해석
- `FAIL` = 위반(금지표현/위험고지 누락) → **exit code 1**. `WARN` = 표시요건 미확인(기본은 실패 아님, `--strict` 시 실패).
- 각 항목에 `[규칙ID]`, 근거 조문, 출처 URL이 붙어 판정 근거를 역추적할 수 있다.
- `PASS` + exit 0 = 위반 없음.

## 근거 데이터 / references
- 룰·조문·출처: `references/ad_rules.json` (banned_expressions / required_disclosures / display_checklist, 각 항목에 `law`·`source_url`).
- 핵심 조문: 금융소비자보호법 제22조(광고 관련 준수사항), 금융투자협회 광고규정.
- 주의: 손실보전·이익보장 **약정**의 형사처벌(3년 이하 징역/1억원 이하 벌금)은 자본시장법 §55·§445 소관이며, 본 스킬이 다루는 광고규제 과태료(최대 1억원, 금소법 §22 계열)와 조문 귀속이 다르다.
