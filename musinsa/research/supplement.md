## 0. 출처 접근 방식 (정직 표기)

- 이 환경에서 **WebFetch는 사실상 전 외부 도메인 403** → 이번 라운드에서는 WebFetch를 시도하지 않고 **WebSearch를 검증 채널로 사용**했다. WebSearch는 각 URL의 실제 기사 본문을 회수·요약해 돌려주므로, 아래의 숫자·날짜·조치는 그 본문 요약으로 교차확인했다.
- 표기 규칙: **`WebSearch 확인 O`** = WebSearch가 해당 URL 본문 요약을 반환해 사실관계를 확인함. URL은 실재하며 공개 접근 가능(단 이 샌드박스 WebFetch 게이트웨이만 403).
- youtube / developers.openai.com / hack.primer.kr 는 지시대로 시도하지 않음.
- SEO 중복/복제 콘텐츠 처리: 동일 사건에 대한 다수 기사는 대부분 **① 무신사 뉴스룸 보도자료** 또는 **② 통신사·단독 1건**이 원본이고 나머지는 재게시(네이트/다음/포털 신디케이션)임 → 아래에서 **원본 1건 + 확인용 복수 URL** 형태로 정리하고, 게시물 수를 문제 크기로 환산하지 않았다.

## 3. 1차 후보 3개 반증·보강 재검증

### 후보 A(추천) — 혼용률·충전재 표시 검증 → **검증 결과: 확인(강화됨), 반증 없음. 단 세부수치 정정 1건**
핵심 주장(7,968개 전수조사 / 8.5% 오기재 / 5~35일 판매중지)은 **무신사 뉴스룸 보도자료 원본 + 복수 언론 재게시로 일치 확인**.
- newsroom.musinsa.com/newsroom-menu/2025-0325 (원본) ; sbs biz 20000224713 ; asiae 2025032516490862001 ; etoday 2455788 ; ebn 1656435 ; edaily 03886806642106928 — 전부 WebSearch 확인 O
- **정밀 수치(보강):** 7,968개 중 **4,577개(57.4%)** 는 공인기관 시험성적서 확인 완료. 성적서 미제출 약 43% 는 무신사가 **직접 구매→인증기관 시험**했고, 이 중 **약 20%가 안전거래정책(허위·과장광고 금지) 위반**으로 나타남. 위반 브랜드에 **최소 5일~최대 35일 전 상품 판매중지** 제재. → 1차 문서의 "8.5% 오기재"는 전체 대비 비율이고, 미제출분만 보면 위반율이 훨씬 높다는 점을 데모 서사에 반영 가능.
- **반복성(강한 보강):** 2025.12 **노스페이스 패딩 13스타일·28SKU 충전재 오기재**('거위털' 표기 vs 실제 상이) 별도 사건으로 재확인 — 단발 아님, 구조적 문제. (nate 20251204n03523 ; ddaily 2025120410110524817 ; newsroom 2025-1202-2 — WebSearch 확인 O)
- **정정 주의(정직):** 노스페이스 건은 1차 문서가 "판매중지"로 적었으나, 회수된 본문상 조치는 **환불 안내 + 판매대행사 벌점 부과**가 명시적이고 '판매중지' 문구는 이 사건 기사에서 직접 확인되지 않음. (혼용률 전수검사 사건의 5~35일 판매중지와 혼동 주의)

## 4. 추가 아이디어 발굴 (1차 후보 3개 외, 브레인스토밍 확장)

> 공통 제약: Codex 플러그인 = python3 표준 라이브러리만·결정론·유료 API 없음·CI 게이트(non-zero exit)·샘플 동봉 재현. 난이도: 상=~1h / 중=~2h / 하=2h+.

### ★ 아이디어 D — 가격 오등록·최저가 정합성 가드 (`price-sanity-guard`) [추천]
- **문제:** 입점 브랜드의 가격 오등록(예: 14.9만→1.49만, 자릿수 실수)으로 초저가 노출→주문 폭주→**무통보 강제취소**→소비자 신뢰 붕괴·PR 사고. 트래커 캐리어 2026.02 사건(정가 26.8만원, 94%↓ 오등록, 1.1에도 유사 재발)이 대표.
- **공개 출처:** 1conomynews.co.kr 46953 ; nate 20260211n38136(=Daum 재게시) — WebSearch 확인 O. (원본 1건이 포털로 신디케이션됨)
- **플러그인 컨셉:** 리스팅 CSV 스캔 → ①자릿수/10배·100배 이상치(정가 대비 판매가 급락) ②할인율 임계치 초과(예 >90%) ③원가/최저마진 하한 미달 ④정가·판매가·쿠폰가 상호 모순 → PASS/FAIL + 교정가 제안. 배포 전 CI 게이트로 "94% off 오타"를 사전 차단.
- **구현 난이도:** **상(~1h)**. 순수 산술·임계치 → 결정론·재현성 최상, 유료 API 불필요.
- **강점:** 후보 A/B/C와 문제영역이 겹치지 않는 **신규 축(가격·운영)**, 최신(2026.02)·구체 사건, 개발/데이터 파이프라인 CI 게이트라는 Codex 유스케이스에 정확히 부합.

### 아이디어 E — 택갈이·자체제작 진위 사전 스크리너 (`oem-authenticity-prescreen`)

### 아이디어 F — 리뷰·랭킹 어뷰징 탐지 (`review-abuse-detector`)

- **구현 난이도:** **상(~1h)**. 순수 표·산술 검증 → 결정론·재현성 높음. 반품(물류) 축 신규.

## 5. 핵심 요약 (최종)

- **후보 A 검증 = 확인(강화).** 7,968개·8.5%·5~35일 판매중지는 무신사 뉴스룸 원본+복수 언론 일치. 세부 정밀화(4,577개 57.4% 성적서 확인, 미제출 43%→시험, 그중 20% 위반)와 **노스페이스 28SKU 반복 사건(2025.12)**, **42개 브랜드 추가 적발**로 구조적 문제 입증. 유일 정정: 노스페이스 건 조치는 '판매중지'가 아니라 **환불 안내+판매대행사 벌점**으로 확인.
- **후보 B·C = 반증 없이 확인.** B는 정보고시 위반 제재 공지 원문 확인, C는 83건·의약품오인 64% 확인 + 국감 기준 **1.2만건·70%** 로 규모 상향 가능.
- **신규 축 발견:** 가격 오등록 강제환불(2026.02 트래커), 택갈이·AI 검수 도입(2026.03), 리뷰/랭킹 어뷰징, 사이즈 반품 — 후보 3종이 못 덮는 **운영·가격·신뢰성** 영역.
- **추천 신규 아이디어 = D(가격 오등록·최저가 정합성 가드).** 최신·구체 사건 + 순수 산술 결정론(재현성·무API) + CI 게이트 유스케이스 정합 + 후보와 비중복. E(택갈이)는 무신사 2026 공개전략과 서사 정합이 최상이나 판정 주관성으로 2순위.
