# 예선 5문항 답변 (사이트 입력용 · 문항당 800자 이내)

> 작성 원칙: 구체적 근거 + 공개 출처 URL 포함, 로그·플러그인과 정합성 유지

## 1. 무엇을, 누가, 어떤 상황에서 쓰나요?

`musinsa-listing-guard`는 무신사 입점 브랜드·판매대행사가 올린 상품 리스팅의 법정 표시 위반을 배포 전에 자동 검출하는 Codex 플러그인(컴플라이언스 스위트)입니다. 스킬 3개로 구성됩니다. (A) verify-textile-labels: 섬유 부위별 혼용률 합계·기타섬유 상한·충전재 표시-시험성적서 대조·필수부위 누락. (B) check-info-notice: 전자상거래 상품정보제공고시 필수항목 누락·공란·'상세페이지 참조' 회피. (C) lint-beauty-claims: 화장품 표시·광고 부당표현.

사용자는 무신사 MD·안전거래센터, 그리고 입점 브랜드 운영자입니다. 상품 등록·수정 시 CI 게이트에서 카탈로그(JSON/CSV)를 검사해, 수천~수만 SKU를 수작업으로 검수하는 대신 SKU별 PASS/FAIL + 위반 사유 + 교정 제안을 즉시 받아 오기재 상품의 배포를 차단하는 상황에서 씁니다.

## 2. 왜 이 문제를 선택했나요?

무신사가 스스로 문제의 실재를 공개 입증했기 때문입니다. 다운·캐시미어 7,968개 전수조사에서 8.5%가 오기재로 적발돼 브랜드에 5~35일 판매중지가 내려졌고(뉴스룸 https://newsroom.musinsa.com/newsroom-menu/2025-0325), 2025-12 노스페이스 패딩 13스타일·28SKU 충전재 오기재가 재발해 환불 안내와 판매대행사 벌점이 부과됐습니다(https://newsroom.musinsa.com/newsroom-menu/2025-1202-2). 정보고시 위반 시 판매중지·주문취소·리콜·퇴점을 공지했고(https://newsroom.musinsa.com/newsroom-menu/2024-1216-musinsa), 식약처 점검에선 화장품 부당광고 83건 중 의약품 오인이 64%였습니다(https://www.newsis.com/view/NISX20250806_0003280269). 반복·구조적 문제이며 산술·사전 규칙으로 결정론적 판정이 가능해 선택했습니다.

## 3. 플러그인은 어떻게 작동하나요?

순수 python3 표준 라이브러리만 사용하며, 판정 기준은 references JSON(각 룰에 조문·출처 URL 필드 포함)에서 읽어 근거를 역추적할 수 있습니다. verify-textile-labels는 부위별 혼용률 합계=100%, '기타섬유' 합계≤15%(전기생활용품안전법 기준), 충전재 표시값과 시험성적서 CSV를 성분별 5%p 이내로 대조, 카테고리별 필수부위 누락을 검사합니다. check-info-notice는 품목별 필수항목의 누락·공란과 '상세페이지 참조' 회피표기를 검출하되 치수 등 일부 항목은 허용합니다. lint-beauty-claims는 의약품 오인·기능성 오인·실증 필요·최상급 4유형 사전으로 텍스트를 라인 단위 스캔하고 조문을 매핑합니다. 모든 스크립트는 위반 시 exit 1, 정상 0, 사용오류 2를 반환하고 `--json` 리포트를 지원해 CI 게이트에 바로 연결됩니다.

## 4. AI를 어떻게 활용했나요?

메인 오케스트레이터(Claude)가 전체 설계·오케스트레이션·품질 관리·최종 패키징을 맡고, 기업별 리서치·구현 서브에이전트(Opus 4.8)를 병렬로 운용했습니다. 서브에이전트는 공개자료(무신사 뉴스룸·법령·복수 언론)를 교차검증하고 반증을 적극 탐색했습니다. 예컨대 노스페이스 충전재 오기재 건의 조치가 '판매중지'가 아니라 '환불 안내 + 판매대행사 벌점'임을 재확인해 1차 서술을 정정했고, 전수조사 수치(7,968개·8.5%·5~35일)는 뉴스룸 원본과 복수 언론으로 일치 확인했습니다. 이렇게 확정한 사실만 결정론적 스크립트와 룰 데이터(조문·URL 포함)로 구현해 재현성을 확보했습니다. AI와의 원본 대화 로그는 편집 없이 `logs/`에 제출했습니다.

## 5. 어떻게 검증했나요?

python3 3.11.15 표준 라이브러리만으로 실제 실행해 검증했습니다. 먼저 모든 JSON을 `python3 -m json.tool`로 검사해 plugin.json·references 3종·samples 4종이 통과했고, 세 스크립트의 `--json` 출력도 json.tool 파이프를 통과했습니다. 다음으로 각 스킬을 위반·정상 샘플로 실행했습니다. verify-textile-labels는 위반 카탈로그 7개 중 4개를 FAIL(합계 오류·충전재 불일치·기타섬유 초과·필수부위 누락)로, 정상 카탈로그는 위반 0으로 판정했습니다. check-info-notice는 4개 중 2개(누락·상세참조 회피), lint-beauty-claims는 위반 후보 17건을 검출했습니다. 위반→exit 1, 정상→exit 0, 존재하지 않는 입력→exit 2가 모두 확인됐고, 명령·결과·exit code를 README 5장에 표로 기록했습니다.
