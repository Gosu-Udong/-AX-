# 예선 5문항 답변 (사이트 입력용 · 문항당 800자 이내)

> 작성 원칙: 구체적 근거 + 공개 출처 URL 포함, 로그·플러그인과 정합성 유지

## 1. 무엇을, 누가, 어떤 상황에서 쓰나요?

myrealtrip-traveler-guard는 여행상품의 취소·환불 약관과 가격표시가 소비자보호 기준을 어기는지 릴리스 전에 자동 검사하는 Codex 플러그인이다. 마이리얼트립 같은 여행 플랫폼의 상품 운영·QA·CI 담당자가, 수많은 상품을 사람이 일일이 검수할 수 없는 상황에서 사용한다. 스킬 두 개로 구성된다. refund-policy-lint는 상품의 취소·환불 정책 JSON을 공정위 「소비자분쟁해결기준」의 위약금 상한과 대조하되, 카테고리(국외패키지·국내여행·숙박·항공권)별로 올바른 기준을 적용해 상한 초과 구간을 잡고 항공권은 '기준 미적용'으로 표시한다. darkpattern-scan은 상품 리스팅 JSON에서 대표가격 오인·숨겨진 필수 수수료·거짓 긴급성·유료옵션 사전선택 같은 가격표시 다크패턴을 검출한다. 두 결과는 통합 리포트로 묶여 신규·변경 상품 배포 전 PASS/FAIL 게이트로 쓰인다. 네트워크·외부 패키지 없이 로컬에서 결정론적으로 돌아 심사자도 그대로 재현할 수 있다.

## 2. 왜 이 문제를 선택했나요?

여행상품의 취소·환불·가격표시 문제는 공개 자료로 반복 확인된다. 한국소비자원 집계상 숙박서비스 분쟁 중 '계약해제·해지'가 최근 3년(2023~2025) 누적 4,079건(65.5%), 2024 단년 1,919건으로 최다다(https://www.kca.go.kr/webzine/board/view?menuId=MENU00307&linkId=334). 공정위는 2024.12 「소비자분쟁해결기준」을 개정해 숙박 24시간 내 취소 위약금 면제를 도입할 만큼 현재진행형 규제 이슈다(https://news.nate.com/view/20241227n13342). 가격표시에서는 한국소비자원이 2024.03 해외 테마파크 입장권 44개 중 16개(36.4%)가 대표가를 아동가/밀쿠폰가로 표시했다고 지적했고 마이리얼트립이 포함됐다(2023.12 개선완료. https://www.khan.co.kr/article/202403121354001). 대표가 환불 분쟁으로 형사고소됐다는 보도도 있으나 단일 매체·결과 미확인이라 단정하지 않고, 견고한 근거는 기준 대비 위약금 상한의 정량 초과로 삼았다(https://traveli.net/news/view.php?no=10700).

## 3. 플러그인은 어떻게 작동하나요?

두 스킬 모두 python3 표준 라이브러리만 쓰는 결정론 스크립트다. refund-policy-lint(scripts/lint_refund_policy.py)는 references/krca_refund_baseline.json에서 상품 category에 맞는 위약금 상한 구간을 고른다. 카테고리 분기가 핵심으로, 국외패키지(30일전 0%/20일전 10%/10일전 15%/8일전 20%/1일전 30%/당일 50%)·국내여행·숙박에는 각 기준을 적용하고, 항공권은 항공사 운임규정이 우선하므로 '기준 미적용(N/A)'으로 표시해 거짓양성을 막는다. 각 취소 시점 위약금이 해당 구간 상한을 넘으면 초과폭·심각도·근거·출처와 시정 제안을 붙여 FAIL한다. darkpattern-scan(scripts/scan_listings.py)은 대표가<모든 옵션가, 미포함 필수 수수료(drip pricing), always_on 긴급성, 유료옵션 기본선택 4룰을 검사해 공정위 유형·출처로 매핑한다. report.py가 둘을 통합 마크다운으로 묶는다. 종료코드는 0=통과, 1=위반, 2=사용오류이고 --json도 지원해 CI 게이트로 붙일 수 있다.

## 4. AI를 어떻게 활용했나요?

메인 오케스트레이터(Claude)가 설계·품질관리를 맡고, 기업별 리서치·구현을 서브에이전트로 병렬 분담하는 구조로 진행했다. 마이리얼트립 담당 서브에이전트가 공개 자료만으로 문제 후보를 발굴하고, 2차 보강 리서치에서 반증·교차검증을 수행했다. 예컨대 대표 고소 사건은 단일 매체·결과 미확인임을 확인해 '소송으로 비화한 분쟁 보도' 수준으로 완화했고, 조정 불수용을 위법으로 프레이밍하지 않도록 근거를 「소비자분쟁해결기준」 대비 정량 초과로 재정의했으며, 소비자원 통계의 연도 라벨(3년 누적 4,079건/2024 단년 1,919건)을 바로잡았다. 린터가 항공권을 단일 기준으로 재단하면 거짓양성이 난다는 점도 반증 과정에서 도출해 카테고리 분기 설계로 반영했다. 모든 주장·숫자에 공개 출처 URL을 병기했고, 구현·검증도 AI가 스크립트 작성과 실제 실행으로 수행했다. 원본 대화 로그는 logs/에 무편집으로 제출한다.

## 5. 어떻게 검증했나요?

모든 스크립트를 샘플로 실제 실행해 확인했다. refund-policy-lint는 정상 샘플(policy_good.json)에서 'PASS 3/FAIL 0/N/A 1', exit 0을, 위반 샘플(policy_bad.json)에서 'PASS 1/FAIL 3/N/A 1', exit 1을 냈다. 항공권은 위약금 100%여도 N/A로 처리돼 거짓양성이 없음을 확인했다. darkpattern-scan은 정상(listings_good.json) exit 0, 위반(listings_bad.json)에서 대표가 오인·drip pricing·거짓 긴급성·사전선택 4유형을 모두 검출하며 exit 1을 냈다. report.py 통합 실행은 '종합 판정 FAIL(위반 8건)', exit 1이었다. 사용오류(파일 없음, 인자 누락)는 exit 2로 분기됨을 확인했다. plugin.json·references·samples의 모든 JSON은 python3 -m json.tool로 파싱 검증했다. 명령·출력·종료코드는 README '6. 검증' 섹션에 그대로 기록했다.
